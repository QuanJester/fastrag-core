# ONNX Model Weights

Thư mục này chứa các file model weights dạng `.onnx` (INT8 quantized):

- `embedding_model.onnx`: Model embedding văn bản.
- `reranker_quantized_int8.onnx`: Cross-encoder reranker INT8 quantized.

> **Lưu ý**: Các file `.onnx` có dung lượng lớn đã được cấu hình trong `.gitignore` để tránh commit nhầm vào Git repository.
